# Понятно — компьютер и смартфон

Учебный курс Центра ментального развития для старшего поколения. Сайт работает на HTML, CSS и JavaScript. Supabase, сервер приложения и установка зависимостей не требуются.

## Содержание

12 занятий: работа с компьютером, смартфон Android, интернет и безопасность, Госуслуги и mos.ru. В каждом занятии есть объяснение, учебное упражнение и три проверочных вопроса. Раздел преподавателя содержит программу для печати.

Продолжительность 12 встреч по 90 минут — предложение для пилота. Расписание и условия участия определяются центром.

## Московское долголетие и практика для жизни

Раздел «Долголетие» связывает очные занятия центра с самостоятельным повторением. Он содержит порядок выбора группы, контакты официального проекта и ссылку на карточку центра. Запись на официальные занятия выполняется отдельно на ресурсах организатора. Набор именно на этот цифровой курс и его расписание уточняются в центре.

Четыре дополнительных тренажёра: выбор группы, проверка показаний воды, подготовка фотографии для близкого и распознавание подозрительного звонка. Это учебные сценарии, не интеграция с государственными аккаунтами. Данные и интерфейс этих разделов находятся в extras.js.

## Прогресс

Результаты сохраняются в браузере на устройстве ученика. Основной курс использует ключ ponyatno-course-v1, дополнительные тренажёры — ponyatno-life-v1. Существующий прогресс основного курса сохраняется. Синхронизации между устройствами и общей ведомости преподавателя нет. Очистка данных браузера удаляет локальный прогресс.

Учебные задания не подключаются к государственным аккаунтам и не отправляют реальные заявления. Ввод паролей, кодов и личных документов не требуется.

## Публикация в GitHub Pages

Адрес после включения публикации: https://nyaganmaksimov-sys.github.io/ponyatno-course/

В Settings → Pages выбрать Deploy from a branch, затем main и /(root). Файл .nojekyll позволяет публиковать готовые статические файлы. После изменения исходников сайт обновляется через GitHub Pages.

## Изменение уроков

Тексты, задания и вопросы находятся в data.js. Логика упражнений — app.js, оформление — style.css. Ссылки на официальные источники доступны в разделе сайта «Источники и памятки».

## Запуск на компьютере

Можно открыть index.html в современном браузере. Для последовательной работы локального сохранения удобнее использовать обычный статический HTTP-сервер.

Сведения о расположении кнопок и условиях государственных сервисов сверяются по официальным источникам перед проведением занятий.

## Презентация заказчику и пилот

Страница [Предложение для организаций](./client.html) описывает действующую демоверсию, подход к проведению пилота и ограничения текущего решения. Публичная ссылка: https://nyaganmaksimov-sys.github.io/ponyatno-course/client.html

**Статус:** проект Центра ментального развития, предлагаемый для потенциального использования в образовательных программах активного долголетия. Официальное партнёрство или техническая интеграция с программой «Московское долголетие» не заявляются.

### Предлагаемая последовательность

1. Показываем рабочий курс и сценарий участника.
2. Согласовываем с клиентом требования, брендирование, учебную программу и ответственных.
3. Запускаем пилот на одной группе с преподавателем.
4. Собираем обратную связь, проверяем понятность интерфейса, корректируем материалы.
5. Отдельно оцениваем необходимость личных кабинетов, общей отчётности и сервера.

Пока нет централизованной ведомости, синхронизации прогресса между устройствами и записи в официальные городские сервисы. Не используйте локальные отметки в качестве официального учёта посещаемости.

## Кабинет ученика

Маршрут `#student` показывает локальный прогресс, достижения, незавершённые задания и результаты жизненных тренажёров. Отчёт можно распечатать. Используются существующие ключи хранения, миграция не требуется. Это не авторизованный аккаунт: на общем устройстве отметки относятся к браузеру, а не конкретному человеку. Официальная аттестация не предусмотрена.

## Рабочее место преподавателя (демо)

`#teacher/groups` — создание условных групп (до 40 участников на группу), расписание, посещаемость, сводка отметок, CSV и печать. Данные сохраняются отдельно под ключом `ponyatno-teacher-demo-v1`. Используются только номера групп и участников; нет авторизации и связи с прогрессом учеников. Сброс демонстрации не затрагивает учебный прогресс. Не использовать для реальных персональных данных или официальной ведомости.

## Кабинет администратора (демо)

`#admin` показывает фактические локальные группы и отметки преподавателя, позволяет добавлять условных преподавателей, назначать их группам, сохранять плановые направления и длительность, распечатывать сводку и образец сертификата. Ключ `ponyatno-admin-demo-v1`. Назначения не являются правами доступа, настройки не меняют уроки, сертификат не подтверждает обучение. Все данные остаются в браузере; использовать только вымышленные номера.

## Стабилизация

Запоминается последний открытый шаг урока. Расписание можно редактировать и удалять. `#backup` позволяет выгрузить и восстановить локальные данные четырёх разделов с подтверждением замены. Не храните в демоверсии реальные персональные данные.

## Понятно HUB

Универсальная демоверсия управления центрами размещена в `hub/`. Ссылка: https://nyaganmaksimov-sys.github.io/ponyatno-course/hub/ . Учебный курс остаётся в корне. HUB использует отдельный ключ localStorage `ponyatno-hub-v1`; резервная копия курса не включает HUB. Только вымышленные данные. Нет авторизации, серверной изоляции, групповой вместимости, возвратов.

HUB v0.2: поиск и карточки клиентов, семейные связи, редактирование услуг, оплаченные абонементы с датами и резервированием занятия при записи. Отмена неоплаченной записи по абонементу возвращает остаток. Возвраты денег не реализованы. Поступления по абонементу учитываются один раз, при оформлении.
HUB v0.2 — обновление публикации.

## Понятно Education

Каталог `/education/` включает 24 программы по шести возрастным и семейным направлениям: 20 новых уроков в трёх курсах (защита от мошенников, логика и внимание для дошкольников, ребёнок в цифровом мире для родителей), исходный курс из 12 занятий и 20 планов будущих курсов. Статусы различаются в интерфейсе. Новый проигрыватель поддерживает учебные ситуации, обратную связь, практику с педагогом и локальные отметки `ponyatno-education-v1`. Отметки не подтверждают освоение навыка; нет авторизации, общей базы, индивидуальных профилей и синхронизации с HUB. Резервные копии прежнего курса не включают этот ключ. Детские материалы требуют сопровождения взрослого и методической проверки. Ссылки на источники безопасности приведены в каталоге.

Education v0.2: добавлены 20 уроков в курсах «Безопасный интернет» (7–10), «Безопасность семьи» и «Современная цифровая жизнь». Всего 40 новых уроков в шести курсах плюс исходные 12 занятий (7 из 24 программ с материалами). Добавлены методические планы, печать, озвучивание средствами браузера и два визуальных учебных примера. Материалы требуют проверки педагогами; рекомендации безопасности нужно актуализировать по официальным источникам.
