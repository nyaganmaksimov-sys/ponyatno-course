# Понятно — компьютер и смартфон

Учебный курс Центра ментального развития для старшего поколения. Сайт работает на HTML, CSS и JavaScript. Supabase, сервер приложения и установка зависимостей не требуются.

## Содержание

12 занятий: работа с компьютером, смартфон Android, интернет и безопасность, Госуслуги и mos.ru. В каждом занятии есть объяснение, учебное упражнение и три проверочных вопроса. Раздел преподавателя содержит программу для печати.

Продолжительность 12 встреч по 90 минут — предложение для пилота. Расписание и условия участия определяются центром.

## Московское долголетие и практика для жизни

Раздел «Долголетие» связывает очные занятия центра с самостоятельным повторением. Он содержит порядок выбора группы, контакты официального проекта и ссылку на карточку центра. Запись на официальные занятия выполняется отдельно на ресурсах организатора. Набор именно на этот цифровой курс и его расписание уточняются в центре.

Четыре дополнительных тренажёра: выбор группы, проверка показаний воды, подготовка фотографии для близкого и распознавание подозрительного звонка. Это учебные сценарии, не интеграция с государственными аккаунтами. Данные и интерфейс этих разделов находятся в extras.js.

## Прогресс

Результаты сохраняются в браузере на устройстве ученика. Основной курс использует ключ ponyatno-course-v1, дополнительные тренажёры — ponyatno-life-v1. Существующий прогресс основного курса сохраняется. Синхронизации между устройствами и общей ведомости преподавателя нет. Очистка данных браузера удаляет локальный прогресс.

Учебные задания не подключаются к государственным аккаунтам и не отправляют реальные заявления. Ввод паролей, кодов и личных документов не требуется.

## Публикация в GitHub Pages

Адрес после включения публикации: https://nyaganmaksimov-sys.github.io/ponyatno-course/

В Settings → Pages выбрать Deploy from a branch, затем main и /(root). Файл .nojekyll позволяет публиковать готовые статические файлы. После изменения исходников сайт обновляется через GitHub Pages.

## Изменение уроков

Тексты, задания и вопросы находятся в data.js. Логика упражнений — app.js, оформление — style.css. Ссылки на официальные источники доступны в разделе сайта «Источники и памятки».

## Запуск на компьютере

Можно открыть index.html в современном браузере. Для последовательной работы локального сохранения удобнее использовать обычный статический HTTP-сервер.

Сведения о расположении кнопок и условиях государственных сервисов сверяются по официальным источникам перед проведением занятий.
