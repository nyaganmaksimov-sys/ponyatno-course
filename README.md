# Умные Лисята — компьютер и смартфон

## Публичный сайт АНО «Солнечные лисята» и готовый показ

`center/` — публичная демонстрация сайта организации: главная с утверждённым логотипом «Солнечные лисята», полный каталог направлений, карточки занятий, информация об АНО, контакты и вход через калитки 2, 3, 4, 5. Посетитель может оставить учебную заявку и следить за статусом. Название «Умные Лисята» используется для связанной учебной системы.

Форма сайта использует тот же ключ `ponyatno-education-workspace-v1` и правила приёма, что и Education. Обращение получает источник «Публичный сайт», контактное лицо и учебный контакт. Оно появляется в кабинете координатора без создания участника. Для зачисления ребёнка координатор должен явно связать заявку с существующим взрослым учебным профилем. После зачисления сайт показывает решение и ссылку на кабинет. Для демо используются вымышленные данные; сетевой обмен между устройствами пока не реализован.

`education/#showcase` — восемь связанных сценариев: шесть направлений центра, семейное обучение и старшее поколение. Кнопка подготовки добавляет отдельные группы, профили, заявки, расписание и работы с разными статусами. Существующие данные сохраняются; повторное открытие не сбрасывает сделанные проверки. Для шести направлений добавляются авторские программы по три вводных занятия. Материалы демонстрационные и требуют проверки педагогами перед реальным применением.

Собственный дата-центр на сервере HPE обозначен в `education/#infrastructure` и `client.html#data-center` как **планируемое преимущество и следующий этап**: контроль хранения, управление доступом, резервные копии и развитие инфраструктуры. Сейчас публикуется только GitHub-демо. Перенос на сервер относится к этапу после завершения и согласования демонстрации.

Новые проверки: `node --test tests/education-showcase.test.cjs`; весь набор: `node --test tests/education-*.test.cjs`.

## Онлайн-выполнение домашних заданий

В Education добавлен связанный демонстрационный процесс: черновик → отправка → проверка → доработка или принятие. Участник может ответить текстом, выбрать вариант учебного ответа, прикрепить фото или документ. Педагог проверяет каждую отправку и оставляет комментарий; история предыдущих попыток сохраняется. Связанный сопровождающий может отправить работу ребёнка, при этом помощь отмечается явно. Педагог также может отдельно зафиксировать выполнение на очном занятии.

- `education/#homework/child/child` — задания ученика; блок и ссылка есть в его кабинете.
- `education/#homework-teacher/children` — очередь проверки с фильтрами группы и статуса.
- `education/#homework-new/children` — выдача группе или одному участнику, необязательный срок и связь со встречей; доступно для всех направлений центра.
- `education/#homework-lesson/<course>/<lesson>` — практика по опубликованному уроку каталога, в том числе по исходным 12 занятиям. Профиль должен подходить по возрастному направлению. Практика из каталога сама по себе не зачисляет в курс.

При назначении курса задания создаются для каждого урока из назначенной версии. Поле «Домашнее задание онлайн» в конструкторе задаёт содержание практики. Поле повторения после очной встречи создаёт задания её участникам; отмена встречи приостанавливает отправку и сохраняет историю. Принятие домашней работы не меняет посещаемость и отметку о разборе урока. Руководитель видит отдельную сводку статусов работ.

Текст, статусы и вложения сохраняются в том же браузере под существующим ключом `ponyatno-education-workspace-v1`, в поле `homework`. Старые профили, назначения и отметки сохраняются при обновлении. Это по-прежнему демороли без авторизации и межустройственной синхронизации: реального сетевого обмена между учеником и педагогом нет. Для реальной эксплуатации нужны сервер, защищённое файловое хранилище и права доступа. Используйте вымышленные данные и учебные файлы.

До двух вложений по 512 КБ: JPG, PNG, WEBP, PDF, TXT, DOCX, XLSX, PPTX. Фотографии уменьшаются до 1280 пикселей и преобразуются в JPEG; файлы сохраняются с содержимым, а не только названием. Общий демонстрационный объём домашних работ ограничен примерно 3 МБ; при ошибке сохранения действие откатывается. Существующие резервные копии старого курса и HUB не включают данные Education.

Проверки: `node --test tests/education-*.test.cjs`. Новый процесс: `education/homework-core.js`, `education/homework.js`, `education/homework.css`.

Учебный курс Центра ментального развития для старшего поколения. Сайт работает на HTML, CSS и JavaScript. Supabase, сервер приложения и установка зависимостей не требуются.

## Содержание

12 занятий: работа с компьютером, смартфон Android, интернет и безопасность, Госуслуги и mos.ru. В каждом занятии есть объяснение, учебное упражнение и три проверочных вопроса. Раздел преподавателя содержит программу для печати.

Продолжительность 12 встреч по 90 минут — предложение для пилота. Расписание и условия участия определяются центром.

## Московское долголетие и практика для жизни

Раздел «Долголетие» связывает очные занятия центра с самостоятельным повторением. Он содержит порядок выбора группы, контакты официального проекта и ссылку на карточку центра. Запись на официальные занятия выполняется отдельно на ресурсах организатора. Набор именно на этот цифровой курс и его расписание уточняются в центре.

Четыре дополнительных тренажёра: выбор группы, проверка показаний воды, подготовка фотографии для близкого и распознавание подозрительного звонка. Это учебные сценарии, не интеграция с государственными аккаунтами. Данные и интерфейс этих разделов находятся в extras.js.

## Прогресс

Результаты сохраняются в браузере на устройстве ученика. Основной курс использует ключ ponyatno-course-v1, дополнительные тренажёры — ponyatno-life-v1. Существующий прогресс основного курса сохраняется. Синхронизации между устройствами и общей ведомости преподавателя нет. Очистка данных браузера удаляет локальный прогресс.

Учебные задания не подключаются к государственным аккаунтам и не отправляют реальные заявления. Ввод паролей, кодов и личных документов не требуется.

## Презентация заказчику и пилот

Страница [Предложение для организаций](./client.html) описывает действующую демоверсию, подход к проведению пилота и ограничения текущего решения. Публичная ссылка: https://nyaganmaksimov-sys.github.io/ponyatno-course/client.html

**Статус:** проект Центра ментального развития, предлагаемый для потенциального использования в образовательных программах активного долголетия. Официальное партнёрство или техническая интеграция с программой «Московское долголетие» не заявляются.

### Предлагаемая последовательность

1. Показываем рабочий курс и сценарий участника.
2. Согласовываем с клиентом требования, брендирование, учебную программу и ответственных.
3. Запускаем пилот на одной группе с преподавателем.
4. Собираем обратную связь, проверяем понятность интерфейса, корректируем материалы.
5. Отдельно оцениваем необходимость личных кабинетов, общей отчётности и сервера.

Пока нет централизованной ведомости, синхронизации прогресса между устройствами и записи в официальные городские сервисы. Не используйте локальные отметки в качестве официального учёта посещаемости.

## Кабинет ученика

Маршрут `#student` показывает локальный прогресс, достижения, незавершённые задания и результаты жизненных тренажёров. Отчёт можно распечатать. Используются существующие ключи хранения, миграция не требуется. Это не авторизованный аккаунт: на общем устройстве отметки относятся к браузеру, а не конкретному человеку. Официальная аттестация не предусмотрена.

## Рабочее место преподавателя (демо)

`#teacher/groups` — создание условных групп (до 40 участников на группу), расписание, посещаемость, сводка отметок, CSV и печать. Данные сохраняются отдельно под ключом `ponyatno-teacher-demo-v1`. Используются только номера групп и участников; нет авторизации и связи с прогрессом учеников. Сброс демонстрации не затрагивает учебный прогресс. Не использовать для реальных персональных данных или официальной ведомости.

## Кабинет администратора (демо)

`#admin` показывает фактические локальные группы и отметки преподавателя, позволяет добавлять условных преподавателей, назначать их группам, сохранять плановые направления и длительность, распечатывать сводку и образец сертификата. Ключ `ponyatno-admin-demo-v1`. Назначения не являются правами доступа, настройки не меняют уроки, сертификат не подтверждает обучение. Все данные остаются в браузере; использовать только вымышленные номера.

## Стабилизация

Запоминается последний открытый шаг урока. Расписание можно редактировать и удалять. `#backup` позволяет выгрузить и восстановить локальные данные четырёх разделов с подтверждением замены. Не храните в демоверсии реальные персональные данные.

## Умные Лисята Education

Каталог `/education/` включает 24 программы по шести возрастным и семейным направлениям: 20 новых уроков в трёх курсах (защита от мошенников, логика и внимание для дошкольников, ребёнок в цифровом мире для родителей), исходный курс из 12 занятий и 20 планов будущих курсов. Статусы различаются в интерфейсе. Новый проигрыватель поддерживает учебные ситуации, обратную связь, практику с педагогом и локальные отметки `ponyatno-education-v1`. Отметки не подтверждают освоение навыка; нет авторизации, общей базы, индивидуальных профилей и синхронизации с HUB. Резервные копии прежнего курса не включают этот ключ. Детские материалы требуют сопровождения взрослого и методической проверки. Ссылки на источники безопасности приведены в каталоге.

Education v0.2: добавлены 20 уроков в курсах «Безопасный интернет» (7–10), «Безопасность семьи» и «Современная цифровая жизнь». Всего 40 новых уроков в шести курсах плюс исходные 12 занятий (7 из 24 программ с материалами). Добавлены методические планы, печать, озвучивание средствами браузера и два визуальных учебных примера. Материалы требуют проверки педагогами; рекомендации безопасности нужно актуализировать по официальным источникам.

Education v0.3: 24 дополнительных урока (ИИ для подростков и взрослых, цифровая безопасность подростков, первые деньги для детей). 11 из 24 программ с материалами, 76 занятий с учётом исходного курса. Шесть самостоятельных сценарных тренажёров по три шага: мессенджер, банк, услуги, ИИ, антимошенник, логика. Это текстовые учебные имитации, не действующие внешние сервисы; прогресс тренажёров пока не сохраняется.

Education v0.5: все 24 программы содержат вводные учебные материалы (142 урока в новом каталоге и 12 в исходном курсе). Добавлен маршрут демонстрации `education/#demo`. Это демонстрационные разработки, не утверждённые полноценные образовательные программы; требуется методическая проверка. Вопросы и тренажёры остаются предметом дальнейшего улучшения.

Сценарий показа: продолжить урок Саши и сохранить отметку, открыть результат у родителя, посмотреть группу у преподавателя. Затем в конструкторе опубликовать пример «Моя первая презентация», назначить его детской группе и открыть у ученика. Изменения отражаются в сводке руководителя.

Все новые кабинеты используют один отдельный ключ `ponyatno-education-workspace-v1`. Отметки обычного каталога (`ponyatno-education-v1`), исходного курса и данные HUB сохраняются отдельно. При прохождении через `#study/...` отметка относится только к выбранному демопрофилю; обычный маршрут `#lesson/...` по-прежнему использует прежний прогресс. Обновление страницы сохраняет состояние, открытые вкладки обновляют кабинеты при изменении этого ключа. Между устройствами синхронизации нет. При недоступном localStorage интерфейс сообщает о невозможности сохранения.

Опубликованный авторский курс хранит копию содержания. Назначение сохраняет свою версию программы: последующие правки, перестановка занятий и повторная публикация не меняют уже назначенный материал и его отметки. Повторная отметка урока не увеличивает прогресс. Черновик нельзя назначить группе; курс другого возрастного направления также не назначается.

Это переключаемые демороли, без авторизации и защищённого разграничения доступа. Все люди, встречи и группы вымышлены. Учебные отметки не подтверждают навыки. Существующие резервные копии курса и HUB не включают новое демо. В разделе «Как устроена демонстрация» можно с отдельным подтверждением сбросить только это демо вместе с авторскими черновиками. Содержимое вопросов и сценариев существующих уроков в этом обновлении не менялось.

Проверки логики: `node --test tests/education-workspace.test.cjs`. Сервер и установка зависимостей не требуются. Исходные файлы нового раздела: `education/workspace-core.js`, `education/workspace.js`, `education/workspace.css`.

Если посещения уже отмечены либо встреча проведена, её время, группа и ресурсы защищены от переноса. Программу и домашнюю практику уточнять можно. Отмена не удаляет встречу; отменённая запись освобождает время, но восстановление проверяет занятость снова. Для отменённых встреч журнал посещений закрыт.

Уведомления о встречах появляются внутри демо у соответствующих участников; родитель получает отдельное уведомление о встрече ребёнка. У каждого адресата собственная отметка прочтения. Время показывается в часовом поясе Москвы. Уведомления не отправляются по почте или SMS. Номер версии локальной схемы и ключ `ponyatno-education-workspace-v1` сохранены; прежние учебные отметки, назначения и авторские курсы дополняются новыми полями без сброса.

## Умные Лисята v0.8 — запись, координатор и занятия центра

На `education/#apply` появилась форма учебной заявки; `#applications` показывает её статус и историю. `#coordinator` содержит очередь заявок, ответственного и дату следующего действия. Доступны рассмотрение, зачисление, лист ожидания, отказ с причиной, отзыв незачисленной заявки и повторное рассмотрение. `#coordinator/groups` — вместимость, набор, настройка и создание групп; `#coordinator/people` и `#participant/<id>` — карточки участников, семейные связи, материалы и заявки.

Зачисление проверяет возрастное направление, программу, вместимость и пересечения встреч уже существующего участника. Повторное зачисление не создаёт дубль. При заполненной группе заявка попадает в лист ожидания без создания лишнего профиля. Очередь обслуживается по порядку. Новые учебные профили появляются после зачисления; заявки не увеличивают число участников. Один профиль может участвовать в нескольких совместимых группах, сохраняя назначенные материалы и отметки. Связанные взрослые получают отдельные уведомления.

По тексту описания группы ВК https://vk.ru/club239727985, предоставленному пользователем в переписке, в каталог добавлены шесть направлений: **Творческая студия (творчество и мастерская)**, **Инженерное направление**, **Интеллект и логика**, **Музыкальные занятия с психологом**, **Английский язык**, **Подготовка к школе**. Адрес и телефон взяты из того же предоставленного описания.

Для занятий центра не назначаются несвязанные цифровые курсы. Группа может работать с расписанием и программой встреч без электронного курса.
